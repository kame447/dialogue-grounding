# アノテーション契約（Annotation Contract）

## 観察可能性の原則

本アノテーションは、参加者の内部状態そのものではなく、発話系列上に観察可能な証拠を記述します。

相互行為上に現れていない「本当は理解していた」「内心では違和感を持っていた」といった状態を推定してラベルを付与しません。

後の最終結果を使って、過去時点の理解や意図を遡及的に確定しません。

## 分析階層

発話機能 a1–a30 は、発話または発話部分が局所的に何をしているかを表します。

ずれ状態 M0–M4 は、参加者間の共有状態がどの段階にあるかを表します。

調整過程 P1–P6 は、表象のずれや理解上の問題に対して、その位置でどのような対処が開始または変更されたかを表します。

エピソード結果 ER0/ER1 は、主要参照対象について上位課題目標がエピソード終了時までに達成されたかを表します。

これらは独立した階層です。a8 があるから M2 や P1、a11 があるから M4 や ER1、という機械的な含意を禁止します。

## 状態ラベルの契約

M0 は、新しい対象またはサイクルに入り、共有上の問題の兆候が観測されない状態です。参加者の内部表象が完全に一致していることを意味しません。

M1 は、共有困難がまだ公然化していない一方、不確かさ、表現の揺れ、判断保留などから共有困難の可能性が示唆される状態です。単なる語探し、命名探索、個人的な確信不足だけでは M1 としません。

M2 は、対象、位置、向き、見立て、課題仕様などについて、不一致または理解上の問題が会話上で公然化した状態です。短い確認質問が存在するだけでは M2 としません。

M3 は、確認、再説明、言い換え、訂正、候補調整などによって共有を作り直している状態です。M ラベルは必須順序を仮定しないため、M1 から M3、M1 から M4 へ直接遷移できます。

M4 は、その時点で扱われている局所問題について共有成立の証拠が得られた状態です。M4 は上位エピソードの達成を意味しないため、M4 と ER0 は両立できます。

M ラベルは状態変化点だけへ記録し、継続行には重複付与しません。

## 調整過程の契約

P1 は、現在の問題に対する修復が直後の局所系列で実際に開始された最初の位置です。M2 は P1 の必須前提ではありません。

P2 は、問題が直後の応答関連位置では修復されず未解決のまま置かれた後、その旧問題そのものの解消を主目的として取り上げ直す過程です。介在発話数の多さではなく、直後に修復が開始されなかったことと、回帰の主目的で判断します。

P3 は、応答が関連する位置で提示内容には反応しつつ、理解成立、採用、不一致、修復要求のいずれも確定的に示されないまま、同一問題について系列が継続する過程です。通常の傾聴や単なるフィラーとは区別します。話者が内的に「保留しよう」と意図したことは判定条件にしません。

P4 は、現在の問題について十分な修復または共有成立が観察されないまま、その問題を明示的に断念せず、別の処理可能な対象または問題へ移る過程です。参加者が内的に「進行を優先した」と考えたことは判定条件にしません。

P5 は、不完全性を残したまま、課題遂行に利用可能な近似した名称、説明、見立て、回答を共同採用する過程です。

P6 は、対象特定やずれ解消を断念したことが系列上明確で、その問題の修復を終了する過程です。一時保留とは区別します。

P ラベルは過程の開始または変更位置だけへ記録し、同一過程の継続行には重複付与しません。

## エピソード結果の契約

ER1 は、主要参照対象について上位課題目標が達成された場合に付与します。本研究では原則として、図形への命名または後続でも識別可能な呼称の共同採用を課題目標とします。

ER0 は、主要参照対象について上位課題目標が未達のままエピソードが終了した場合に付与します。

ER は原則として episode end 行だけへ付与します。

## エピソード境界の契約

エピソードは、同じ主要参照対象を共同で特定・命名し、その対象について課題を進める上位範囲です。

同一対象について位置、特徴、対象同定、見立て、名称へ問題次元が変化しても、原則として同一エピソードを維持します。

別の主要対象へ移る場合、未解決対象を閉じるまたは保留して別対象へ入る場合、課題目標自体が変わる場合を境界候補とします。

a7 や M4 の出現だけではエピソードを分割しません。

## 発話機能の契約

発話機能は最小限の文字列範囲へ付与します。同じ範囲に独立した複数機能が成立する場合は複数ラベルを許可します。

重なり発話は親話者から分離し、重なり話者側の部分として判定します。

通常部分のラベルなし span は出力しませんが、重なり部分はラベルなしでも位置と話者を保持するため出力します。

文字位置は正規化後原文の先頭を 0 とする半開区間で記録し、重なり除去によって一つの機能が分断される場合は複数区間を保持します。
