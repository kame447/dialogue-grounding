# Annotation

既存の対話データに対するアノテーションと、その作業を Jev / 生成モデルで支援するための領域です。

このフォルダの目的は「人間がどのような内部状態にあったかを推定すること」ではなく、発話系列上に観察可能な証拠に基づいて、発話機能 a1–a30、ずれ状態 M0–M4、調整過程 P1–P6、エピソード結果 ER0/ER1 などを一貫して記述することです。

Jev は研究仮説そのものを検証するモデルではなく、閉集合判断を支援する一次判定器として扱います。最終的な研究用ラベルは人間が確認します。

主な文書は annotation-contract.md、context-and-state.md、evaluation.md、roadmap.md です。

対話そのものを LLM でモデル化し、「やり過ごし」が共通基盤形成に果たす役割を検証する設計は ../dialogue-model/ に分離します。
