# Decisions

> 文書区分：議論・決定根拠の保存場所。実験計画の唯一の正本は[現行計画（SSOT）](../README.md)です。採用した変更は必ずSSOTにも反映し、このディレクトリの資料を独立した「最新版」として扱いません。

実験設計やモデル構造のうち、議論を経て採用した重要な判断を、理由と代替案とともに残す場所です。

このディレクトリは設計判断が正式に決まった時点で使います。未確定の内容を決定事項として記録しません。

新しい決定記録は `0001-short-title.md` のように連番で作成し、少なくとも「決定日」「状態（accepted / superseded）」「背景」「採用した判断」「代替案」「採用理由」「影響範囲」を含めます。

後から方針が変更される場合は、古い記録を消すのではなく、新しい決定記録から旧記録への置換関係を明示します。
