## 読み方

- 新しい文書と古い文書が食い違うときは、新しい文書を優先します。古い文書は書き換えず、冒頭の案内で状態を示します。
- 2026-10-12 の再協議依頼に応じた Opus／Astra のレビュー草案は、研究者未承認のため Git に入れていません。状態は [reviews/](../reviews/README.md) にあります。
- 実験UIの仕様メモ（2026-10-13-interface-prototype-task.md）は draft PR #1 にだけあり、main には未マージです。

## 更新方法

ここに保存された案は確定仕様ではありません。通常の細部修正は Git の差分で管理し、研究の問い・比較条件・主要評価指標などに大きな変更があったときは、新たな日付付き案で変更点と理由を示します。採用した重要な設計判断は [decisions/](../decisions/README.md) に残します。
