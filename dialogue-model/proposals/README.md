# Proposals

対話モデルに関する検討中の実験案と研究者の意図整理を、日付付きの文書として保存する場所です。

## 最新の研究意図・再協議依頼

[2026-10-12 研究者との対話整理・負荷と円滑さの再協議依頼](2026-10-12-research-clarification-and-measurement-brief.md)は、初期案の後の対話をまとめたものです。研究の中心を「人間がずれや不確実性を許容し、成功を保ちながら負担を下げる過程」に置き、やり過ごしをその一手段と位置づけています。共同命名の成功基準、消去法を排除しない方針、楽さと円滑さの区別、尺度の文献確認と具体的質問紙の設計を再協議事項として記録しています。状態はdiscussion-summaryであり、エージェントの検討結果や採用済み実験仕様ではありません。配送状況は本文のreview_statusで区別します。

## 初期案の履歴

[2026-10-12 初期実験計画](2026-10-12-initial-experiment-plan.md)は、初回に検討した研究目標、即時修復型／やり過ごし許容型、評価指標、図形課題、三層構造を保存したdraftです。最新の研究意図と同一ではないため、過去の検討記録として参照します。

## 更新方法

ここに保存された案は確定仕様ではありません。通常の細部修正はGitの差分で管理し、研究の問い・比較条件・主要評価指標などに大きな変更があったときは、新たな日付付き案で変更点と理由を示します。採用した重要な設計判断は[decisions/](../decisions/README.md)に残します。
