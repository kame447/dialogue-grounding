# 研究工程（Roadmap）

> 状態：partly-superseded（2026-10-06 作成）。段階の大枠は参考になりますが、Phase 3〜5 の課題・比較条件は、6図形の共同命名と人間参加者による A／B 参加者内比較へ具体化されています（[2026-10-13 明確化](proposals/2026-10-13-researcher-clarification.md)）。実験UIの試作の状況は [研究の現在の状態](../docs/current-research-status.md) を参照してください。

## Phase 0: 仮説固定

中心仮説を、やり過ごしが共通基盤形成に寄与する機能的な調整となり得ることに置く。

内部表象の真値推定を研究目的から外し、観察可能な対話系列と課題結果を分析対象に固定する。

## Phase 1: 既存人間データの再分析

即時修復された問題も含め、局所問題を共通の単位で追跡する。

やり過ごしの発生条件だけでなく、やり過ごし後に説明継続、別問題の進行、後続再処理、課題上十分な共有の形成がどう起きているかを確認する。

## Phase 2: 機構仮説の抽出

既存データから、判断保留、持ち越し、次善的合意が何を可能にしているかについて、LLM で比較可能な仮説へ落とす。

観察データだけから因果関係を断定しない。

## Phase 3: 対話課題の設計

局所問題を未解決のまま一時的に進行でき、後続情報によって再処理できる余地を持つ課題を設計する。

特定のずれ種類そのものを研究目的にせず、問題を時間的に配分する調整過程を観察できることを優先する。

## Phase 4: LLM 対話モデル

repair-first と bypass-enabled を同一条件で実装する。

両者には、その時点までの発話と課題情報だけを与える。

## Phase 5: 比較実験

課題達成、共有成立、発話数または時間、修復回数、保留問題の再処理、未解決問題、失敗を比較する。

人間データとの比較では内部状態ではなく、観察可能な時間的系列を比較する。

## Phase 6: 一般化

異なる対象・課題でも同様の利点と限界が再現されるかを検討する。

最終的には、やり過ごしをタングラム固有の現象ではなく、不確実性の処理を時間的に配分する共通基盤形成上の調整原理として説明できるかを検討する。
