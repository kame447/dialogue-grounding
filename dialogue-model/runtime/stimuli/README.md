# 合成タングラム刺激（予備試験用）

この6図形は実装確認用の合成刺激であり、実験で正式採用された刺激ではない。研究計画の正本は [dialogue-model/README.md](../../README.md)。意味のある図形名は付けず、各図形は標準7片（面積合計8）の整数座標から構成する。

Node.js 22以上、追加npm依存なし。

```sh
npm test
node dialogue-model/runtime/stimuli/preview.mjs --seed 17 --out /tmp/tangram-preview
```

出力は `human.png`、`ai.png` と、人間側スロットを表すファイル名の単体PNG6枚。出力先はリポジトリ外を推奨する。図形IDや対応表はstdoutのみに出力する。stdoutも採点者専用とし、AIや参加者に渡さない。

`createTrial({ seed })` は同じ安全な整数seedから同じ試行を生成する。画像は1200×800、白背景に黒いシルエット、2段3列。文字・番号・ピース境界・PNGメタデータは含まない。両者の全図形の位置と回転（90°単位）を変え、表示間の鏡映はしない。表示面積の尺度は両者・全図形で共通。`key` と `createLayouts` の内容は研究側専用で、モデル入力に含めない。

`scatter-v2.mjs` の `createTrialV2({ seed, rotationMode })` は `ROTATION_MODES` の2方式を受け付ける。`relative_pm90`（既定・旧記録）は人間側の角度にAI側でさらに±90°を加える。`relative_0` はAI側の各図形を、人間側の同じ図形と同じ角度にする。人間側の全体と、スロットと図形の対応は同じseedで両方式に共通。AI側の配置は図形の外接矩形が変わるため同一とは限らない。生成時の方式・角度・刺激版は `trialStimulusV2(trial)` で研究記録にだけ保存する。どちらを実験で使うかは研究者が決める。

幾何検証は各片の距離による合同判定、凸多角形クリッピングによる交差面積、共有辺の連結性を確認する。整数格子と45°方向の辺を使い、浮動小数点許容誤差は1e-8。ラスタ近似で重なりを判定しない。シルエット境界から内部辺を除き、45°単位の全回転と鏡映で6図形の相異を検証する。描画は2倍のスーパーサンプリングで境界のみ灰色になる。

`../scoring.mjs` の `scoreTrial` は対応表を介して最終提出だけを比較する。`matchedCount`、`figures`、両側の `duplicateNames` と `unnamed` を返し、6一致かつ重複名なしを暫定成功とする。未指定スロット・空文字は未命名で、一致に数えない。不正なスロット・非文字列はエラー。NFKC、空白除去、カタカナからひらがなへの変換は暫定的な表記正規化であり、同義語や意味の一致は判定しない。結果は常に `provisional: true`。

図形の見分けやすさ、向き変更による負担、適切な図形セット・サイズ・配置、および表記揺れ・部分成功・重複名の正式な採点規則は未決定。予備試験と研究者の確認が必要。
