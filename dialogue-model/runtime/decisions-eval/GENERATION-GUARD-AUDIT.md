# 合意表現の公開前検証：独立監査

**工学的監査・研究者未承認。** 正本は [../../README.md](../../README.md)。ORRERY #6331 / #6334 / #6341 の仕様に対し、GrayLavoisier worktree の `c622573` 上の実装を読み取り専用で監査した。監査者の変更はこの文書と `tests/generation-guard-audit.test.ts` だけであり、ソースの編集・複写、実API、keychain、wrangler、デプロイ、依存追加、commitは行っていない。

判定：**指摘したP1/P2と代替文の安全性対策を確認。指定された語彙・状態境界に未解消の阻害的指摘はない。** 独立テスト15/15、提供された合成発話29件の独立分類、実装側の全体テスト636/636が成功した。監査テスト15件は636件にはまだ含まれないため、親で統合後の全件実行が必要。

## 実装境界

- `v2/dialogue-v2.mjs:210–235` は通常／activeの両方で、最終主actionが非agreeなら生成文を検査する。合意表現があれば1回だけ再生成し、再生成がなお違反・空・不正型・接続失敗なら安全な代替文を返す。通常の初回接続失敗は従来どおりエラーであり、成功した対話を装わない。
- 再生成指示は公開履歴の後のsystemメッセージ1件で、最終actionと既存 `ACTION_SCOPE_V2` を使う。棄却した下書き本文、元のLuna判断、モデル応答の生エラーは追加しない。
- `abortIf` は初回結果の後と再生成のcatchの外にある。初回後に中断すれば2回目は始まらず、再生成中の接続失敗と中断が重なっても代替文を成功として返さない。
- `applyJudgment` とgraphの適用は検査・中断検査の後に1回だけ行う。検出語からactionを逆算したり、agreeへ変更したりしない。再生成や代替文を使っても型付き判断は維持され、propose_nameはtentativeのままである。
- private traceは `generationGuard = { violations: codes[], regenerated, fallback }` だけを追加する。コードは重複を除き、下書き・生のエラーを含めない。参加者状態には現れない。
- キューで古くなった再生成は確定されない。再生成を止めている間に新しい人間発話を追加した独立テストでは、現行スナップショットの公開返答と判断が1件だけ確定し、棄却文・guard診断は参加者に現れなかった。
- 方略別の教示は不変。両方略の生成・再生成・代替文と最終状態は同じ。v1実装・schema・Workerには今回の変更がなく、既存v1回帰テストも全体テストに含まれる。

## 独立検証

`tests/generation-guard-audit.test.ts` はNode 24の型除去で実行する新規TypeScriptテスト。ソースを読み取り専用に保つため、対象import URLだけメモリ上でGrayLavoisier worktreeへ置き換えた。

1. 宣言形、句読点、改行・空白・ゼロ幅空白の検出。
2. 質問・提案・単なる見立てへの「いいですね」の許容。
3. 宣言の後の質問や混合節による検出回避の防止。
4. 追加された活用形と、実生成の公開経路での拒否。
5. 型検証を通る悪意ある名前／特徴の安全な代替文。
6. 棄却文・再生成失敗の生エラーを履歴／traceへ含めないこと。
7. 空・不正型の再生成でも追加呼出しは最大1回。
8. 生成の修正後もledger・grounded memoryを一度だけ適用。
9. 初回後・再生成失敗中の中断と、元状態の不変。
10. 主agreeの検査省略、方略間の同一性、古い再生成の破棄、通常／active両方の参加者状態と発話。

最終結果は**15/15成功、失敗・cancel・skip・todoなし**（`/tmp/brisk-generation-guard-audit-after.tap`）。供給された29件も別の手動分類表で検査し、9件の非agreeの命名宣言を検出、2件の主agreeでの宣言も字句上は検出、残る質問・見立ては非検出となった。実装側の `npm test` も監査者が独立実行し、**636/636成功、失敗・cancel・skip・todoなし**（`/tmp/brisk-generation-guard-gray-full.tap`）。実モデルの再呼出しは行っていない。

## 結論の限界

保証できるのは、定義した日本語の字句群について、非agreeの公開出力が検査を通り、通らなければ安全な固定文まで退避するという境界である。質問・保留との区別を行う有限の字句検査であり、あらゆる言い換え・暗黙の合意・他言語・引用・談話の意味を判定するものではない。誤検出は再生成や定型応答を増やし、会話の負担や方略の見え方を変え得るので、guardの頻度と費用を研究記録から確認する必要がある。

主actionがagreeなら仕様どおり検査を省略する。主agreeと非agreeのfollowUpが同じ発話に含まれる場合、どの名称・図形に各合意表現がかかるかまでは保証しない。図形の正しい同定、相手の受容意図、意味的な誤合意も従来のモデル解釈に依存する。この検査は共有同定を作らず、語の検出から研究上の状態を確定しない。

合成発話29件とモックの成功は、修正前の語彙的不整合に対する回帰検証である。実際の対話での成功率、円滑さ、負担の改善や方略差の維持を示す結果として扱わない。
