# 観察メモ（研究用 opt-in）

現行計画の[判断の権限と観察](../../README.md#判断の権限と観察2026-10-20採用)と[決定0002](../../decisions/0002-jev-decision-and-visual-observation.md)に基づく、Luna（生成モデル）による自分側の図形の観察です。対話の行動は決めません。行動はJevが決めます。

## 何をするか

試行の開始時の**初回観察**では、AI自身の画像と、自分の6図形のIDと画像内の座標（`ownAnchors`）だけをLunaに渡し、図形ごとに次を記録します。
- 見立て（holistic）：全体や部分が何に見えるかの仮説。根拠になった画像の部分を添える。常に仮説として扱う。
- 形の記述（analytic）：形・構成・部分どうしの関係。見立てとは分けて記録する。
- 不明点（unknowns）：まだ分からないこと。

**再観察**は、Jevが図形と論点を指定したときだけ行います。根拠・反証・不明を返し、初回メモには上書きせず追記します。

## 指示文について

初回観察の指示文（`observe.ts` の `OBSERVATION_INITIAL_INSTRUCTIONS`）には、馬・牛・鳥など特定の名称やカテゴリの例を入れていません。例示によって見立てが特定の方向へ寄ることを避けるためです。見立ての上限（8）は数の上限であって、出すべき数ではありません。根拠が見えなければ見立ては空でかまいません。指示文の変更は研究者の確認を経てから行います。現行計画の文書に出てくる「馬っぽい」は読み手向けの説明であり、モデルには送りません。

## 初回観察のキャッシュ（2026-10-20採用、実装は別途）

同じ図形セットのAI側の描画について、初回観察メモを一度作って検証し、保存して各試行で読み込みます。照合には、AI側の画像の内容のハッシュ、図形のIDと座標・向き・配置、観察に使ったモデル・指示文・メモの形式の版を使います。一つでも合わなければ使いません。キャッシュには相手の画像・正解対応・参加者のデータを含めません。対話中の再観察や合意・否定・名称は、その対話だけのメモに記録し、キャッシュを書き換えません。
