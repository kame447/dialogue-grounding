6図形の共同命名

AIと会話して、同じ図形に同じ名前を付けてください。相手の画面では配置と向きが異なります。

研究者用：試行の開始

研究者用：補助機能（既定OFF）

実験条件・採点規則は暫定です。研究者が開始してから参加者に画面を渡してください。

あなたの図形

図形を選ぶと拡大できます。会話で共有した名前は、自分のメモとして入力できます。

入力した名前や図形の選択は相手に届きません。名前を共有するには、メッセージで伝えてください。

対話

    Enterで送信・Shift+Enterで改行

    会話で共有した名前を提出

    すべての図形を選んで名前を入力するか、「未合意・わからない」を選んでください。提出前に確認・修正できます。

    照合結果（暫定）

    図形のそばに、あなたとAIの名称・暫定照合を表示しています。正式な採点規則は検討中です。

    この図形の名前

    会話で共有できたと思う名前を入力してください。この入力は相手には届きません。

    この回答を提出しますか？

    図形のそばの名前を確認してください。提出すると対話を終了し、回答を変更できなくなります。
