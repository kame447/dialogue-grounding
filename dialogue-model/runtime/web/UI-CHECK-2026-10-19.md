## 確認結果（main 時点）

| 項目 | 結果 |
| --- | --- |
| 冒頭発話 | AIの通常吹き出しとして最初に表示 |
| 楽観的吹き出し | 送信直後に表示、入力欄を空にしてフォーカス維持 |
| 入力中ドット | 送信中・AI応答待ちに表示、応答後に消える |
| Enter = 改行 | Enter で改行のみ。送信はボタンだけ |
| 送信失敗（POST通信失敗） | 吹き出しに「!」と「再送」。再送で重複なし |
| AI失敗 → 再試行 | 「返答を取得できませんでした」と再試行ボタン。再試行で応答が追加される |
| 再読込 | 公開履歴と名前メモ（sessionStorage）が復元され、履歴末尾にスクロール |
| スクロール | 上に戻って読んでいる間は新着で位置を保持（既存テストの意図どおり、自分の送信でも末尾へ飛ばない） |
| 名前段階 | 一覧から入力、「未合意・わからない」、未回答の警告 |
| 確認ダイアログ | 盤面と名前を表示、提出前の最終確認 |
| 結果 | 図形横に「あなた／AI・一致／不一致」、ステップ表示が結果へ |
| /v1/ | 表示・試行開始とも可。v2 の試行は表示されない（版の分離） |
| 横はみ出し | 全段階・全サイズで `scrollWidth == innerWidth` |

| ID | 重大度 | 内容 | 対応 |

## スマホ配置（WildBose 承認、幅760px以下・会話段階のみ）

盤面（35dvh）を常に上部に表示し、その下で会話ログが独立してスクロールし、入力欄も常に見える1画面配置にした。横向きで高さ500px以下なら盤面と会話を左右に並べる。名前段階・結果段階と、幅761px以上（デスクトップ）は従来どおり。

`dvh` を使うため、ページ全体は1画面に収まる。盤面は sticky ではなく、ページがスクロールしないので常に見える。
