# 研究・実験計画

最終更新：2026-10-13  
状態：研究方針は整理済み、実験プロトコルは設計・協議中

**現在地と進め方**：現在は実験設計段階であり、実施済みの比較実験結果はない。まず、方略差を自然な対話として実装・操作確認できるか、共同命名の採点が安定するか、参加者の負担と円滑さをどの尺度で測るかを固める。続いて予備実験で実施可能性と効果のばらつきを確認し、本実験の規模と分析方法を判断する。なお、2026-10-12に依頼されたOpus 5.5およびAstraによる独立検討は着手が記録された段階であり、成果物の採用や最終的な統合案の確定を意味するものではない。

## 研究の目的

### 仮説
人間は、対話中の表象のずれや不確実性をすべて厳密に解消するのではなく、課題達成に支障のない範囲では曖昧さを許容することで、共同活動の成功を保ちながら会話の負担を軽減しているのではないか、という仮説を検討する。

### やり過ごしの位置づけ
「やり過ごし」はそのような省力的調整の一手段である。判断保留、別問題への移行、後からの再処理、次善的合意、消去法を含め、どのような調整が共同活動に十分な共通基盤の形成に役立ち、どのような場合には失敗につながるかを調べる。やり過ごしの発生回数を増やすことや、LLMを人間らしく見せること自体は目的ではない。

### 主張の範囲
モデル比較によって示せるのは調整方略の機能や人間対話との対応であり、LLMで似た行動が出るだけで人間の内部認知機構まで証明したとは主張しない。一方で、人間のコミュニケーション・認知過程の理解という研究目標自体を捨てるわけではない。

## 実験の概要

### 共同命名課題
基本課題は、二者が6つのタングラム図形について、同じ対象に同じ名前を共同で付ける命名課題とする方向で検討する。既存の人間対話では、同一図形を異なる配置・向きで提示しており、この構造を比較の出発点にする。

命名後の別個の識別課題や共同配置課題は、現行計画の必須要素ではない。必要性が具体的に示された場合だけ追加を検討する。

### 成功基準
中心的な成功指標は、二者の最終的な「図形と名称の対応」が一致するかどうかである。見立て、詳細な形状説明、内部表象まで一致することを条件にしない。「残った図形はこれだろう」といった消去法も、正しく名称が共有されれば成功に含める。

## 具体的な手順・比較条件

### 2つの対話方略
同じ基盤LLM、同等の画像・履歴・課題情報、原則同じ会話能力・推論条件を使い、理解上の不確実性をどの程度その場で確認するかという方略の違いを比較する。

- **確認・修復を優先する条件**：不明確な内容や共有上の問題を検出したとき、必要な確認や再説明を比較的早く求める。
- **曖昧さを許容する条件**：必要なら直ちに修復しつつ、状況に応じて判断の保留、別の図形・論点への移行、後からの再処理、実用上十分な合意も選べるようにする。

どちらの条件でも自然な相槌や受容応答は使用できる。

本比較は「必ず質問する」対「質問を禁止する」という極端な比較ではない。厳密条件を同じ質問の反復で不自然に劣化させず、対話ログ上で確認・保留・再処理などの行動差が実際に生じたかを別途検証する。また、単なる確信度の低さを確認の必要性と同一視しない。

### 対話モデルへの情報統制と画像の扱い
- **画像の扱い**：図形は実験者があらかじめ「鳥」「船」などの文章に変換せず、マルチモーダルLLMに画像として提示する。
- **情報統制**：対話モデルには、自分に提示された図形・課題指示、それまでに公開された発話・行動など、参加者がその時点で利用できる情報のみを与える。相手だけの画像、正解対応表、完成済みアノテーション、未来の発話、事後的な回答は渡さない（採点器が正解表を持つこととは厳密に分ける）。

### モデル構成の構想
会話・認識、方略判断、状態管理・実行の三層に責務を分ける構想を検討している。

## 測定・評価

### 課題成功と主観的負担・円滑さ
まず共同命名の成功と誤対応を評価する。そのうえで、人間側の主観的な「楽さ（理解・記憶・推測・説明等の努力や負担）」と「円滑さ（停滞や手戻りが少なく進めやすい感覚）」を別々の概念として検討する。確認が多くても考える負担が軽い場合や、会話が速くても推測負担が重い場合を区別するためである。主観評価の質問紙と自由記述を組み合わせ、必要に応じて客観ログと照合する。

### 客観ログ
発話・ターン数、発話量、所要時間、確認・修復の回数、判断保留・再処理、誤りや未解決問題などを記録する。会話が短いことをそのまま認知負荷の低さとはみなさない。

### 尺度候補
主観評価の候補として、NASA-TLX、Paasの精神的努力、PARADISE、BUS-15等の文献確認を行っている。

### 同等性の扱い
本実験が期待するのは、課題達成を実質的に損なわずに負担または対話の停滞を抑えられるかの検証である。「成功率に統計的有意差がない」ことのみをもって同等と結論しない。何をもって十分な成功維持とするか、分析単位と統計計画も設計する。

- **実験デザイン・実施要領**

  - 新実験での画面表示、参加者構成の細部
  - 時間制限の有無および設定
- **課題・採点規則**
  - 6図形中の部分成功、重複名、表記揺れ、未命名、時間切れの採点規則
  - 命名後の別個の識別課題や共同配置課題の追加要否（必須要素ではなく、必要性が具体的に示された場合のみ検討）
- **モデル構成・アルゴリズム**
  - 三層構造（会話・認識、方略判断、状態管理・実行）の具体的な層数、API、使用モデル、判断閾値
  - Jev等の判断モデルで閾値を操作する案（候補であり採用済みではない）
- **測定・尺度・統計計画**
  - 主観尺度の選定（NASA-TLX、Paasの精神的努力、PARADISE、BUS-15等は文献確認を要する候補であり、正式採用された尺度・設問ではない）
  - 主観尺度の日本語版の妥当性、回答段階、実施時点、得点化方法
  - 何をもって十分な成功維持とするかの基準、分析単位、および統計計画の策定
