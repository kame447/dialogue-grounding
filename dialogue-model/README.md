# Dialogue Model

人間対話で観察された「やり過ごし」が、共通基盤形成にどのような役割を持つかを、LLMによる対話モデルで検討する領域です。

中心仮説は、局所的な不確実性をすべてその場で修復せず、必要に応じて判断保留や問題の持ち越しを行うことが、共同活動に十分な共通基盤形成に寄与する場合がある、というものです。内的認知状態の直接推定や、人間の認知プロセスの証明を目的としません。
