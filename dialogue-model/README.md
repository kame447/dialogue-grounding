# Dialogue Model

人間対話で観察された「やり過ごし」が、共通基盤形成にどのような役割を持つかを、LLMによる対話モデルで検討する領域です。

中心仮説は、局所的な不確実性をすべてその場で修復せず、必要に応じて判断保留や問題の持ち越しを行うことが、共同活動に十分な共通基盤形成に寄与する場合がある、というものです。内的認知状態の直接推定や、人間の認知プロセスの証明を目的としません。

## 最新の研究者意図

[2026-10-12 対話整理・負荷と円滑さの再協議依頼](proposals/2026-10-12-research-clarification-and-measurement-brief.md)を先に参照してください。研究者は上位の問いを「人間がずれや不確実性をある程度許容し、課題成功を保ちながら会話負荷を下げる過程」と明確にしています。やり過ごしはその一手段です。人間のコミュニケーション過程が最終的な研究対象であることと、LLMの挙動再現だけでは人間の内部機構を証明できないことを区別します。

同文書には、共同命名を成功基準とする希望、消去法を排除しない方針、楽さと円滑さを分ける評価、尺度の文献確認・質問紙案への要求を記録しています。以下の資料はこの整理を踏まえて再検討する対象であり、すべてが更新済みという意味ではありません。追加のエージェント協議の配送状況は同文書に記録し、保存だけで協議開始とみなしません。

## 時間軸に沿った記録

[proposals/](proposals/README.md) — 日付付きの検討案と変更理由。案は採用が決まるまでdraftとして扱います。

個別の小さな修正はGitの履歴で追い、重要な実験方針を変更したときは、新しい日付付きの提案または決定記録から前の文書を参照できるようにします。古い初期案を黙って現行仕様へ書き換えません。

## アノテーション領域との分離

観察された人間対話のラベル体系やJevによるアノテーション支援は[annotation/](../annotation/README.md)で管理します。この領域では、同じ現象を再現・比較する対話モデルを扱います。

実データ、音声、完成済みアノテーションファイル、個人識別情報はGitリポジトリに置きません。
