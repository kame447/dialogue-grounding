# 対話モデル（Dialogue Model）

人間対話で観察された調整を、LLMによる対話モデルと人間参加者の実験で検討する領域です。全体の目次は [文書総合目次](../docs/README.md)、決定・未決の一覧は [研究の現在の状態](../docs/current-research-status.md) にあります。

## 最新の研究者意図（この順に読む）

1. [2026-10-13 研究者による明確化](proposals/2026-10-13-researcher-clarification.md) — **最新**。上位仮説を「タングラム6図形の共同命名で、ずれ・不確実性の許容が、成功を維持しつつ精神的努力と会話の円滑さにどう影響するか」と明確化しました。6図形を区別できる名前を必須条件とし、A／B は同じ参加者が両方体験（AB／BA 均衡化）、精神的努力は名前を決める会話中のものを尋ね、形状・見立てと対象対応の判断は単一のマルチモーダルLLMに統合する方針を優先します。
2. [2026-10-12 対話整理・負荷と円滑さの再協議依頼](proposals/2026-10-12-research-clarification-and-measurement-brief.md) — 共同命名の成功基準、消去法を排除しない方針、楽さと円滑さの区別、尺度の文献確認の要求を記録しています。上記の明確化と食い違う場合は明確化を優先します。

やり過ごしは許容を実現する方略の一つです。LLMの挙動再現だけでは人間の内部機構を証明できないことを区別します。

## アノテーション領域との分離

観察された人間対話のラベル体系や Jev によるアノテーション支援は [annotation/](../annotation/README.md) で管理します。この領域では、同じ現象を再現・比較する対話モデルと実験を扱います。

実データ、音声、完成済みアノテーションファイル、個人識別情報は Git リポジトリに置きません。
