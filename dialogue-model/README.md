# 研究・実験計画

最終更新：2026-10-13  
状態：研究方針は整理済み、実験プロトコルは設計・協議中

**現在地と進め方**：現在は実験設計段階であり、実施済みの比較実験結果はない。まず、方略差を自然な対話として実装・操作確認できるか、共同命名の採点が安定するか、参加者の負担と円滑さをどの尺度で測るかを固める。続いて予備実験で実施可能性と効果のばらつきを確認し、本実験の規模と分析方法を判断する。

## 研究の目的

### 研究の問い
タングラム6図形の共同命名において、ある程度のずれや不確実性の許容が、課題成功を維持しつつ、精神的努力と会話の円滑さにどう影響するかを問う。

### やり過ごしの位置づけ
やり過ごし（判断保留・持ち越し・暫定的合意など）は、この許容を実現する方略の一つである。それ自体の回数や分類、あるいはLLMを人間らしく見せること自体を最終目的とするのではない。判断保留、別問題への移行、後からの再処理、次善的合意、消去法を含め、どのような調整が共同活動に十分な共通基盤の形成に役立ち、どのような場合に失敗につながるかを調べる。

### 主張の範囲
VLM／マルチモーダルLLMの挙動だけで人間の内部認知機構まで証明したとは主張しない。人間参加者の成功・努力・円滑さの評定と、モデル内部の構成比較で示せることを区別する。モデル比較によって示せるのは調整方略の機能や人間対話との対応であり、人間のコミュニケーション・認知過程の理解という研究目標自体の位置づけを整理して進める。

## 実験の概要

### 共同命名課題
二者が6つのタングラム図形について、互いに区別できる名前を共同で付けることを必須の基本課題条件とする。既存の人間対話では、同一図形を異なる配置・向きで提示しており、この構造を比較の出発点にする。

命名後の別個の識別課題や共同配置課題は、現行計画の必須要素ではない。必要性が具体的に示された場合だけ追加を検討する。

### 成功基準
中心的な成功指標は、二者の最終的な「図形と名称の対応」が一致するかどうかである。見立てや詳細な形状説明の一致、内部表象の一致は成功条件にしない。「残った図形はこれだろう」といった消去法も、正しく名称が共有されれば成功に含める。

## 具体的な手順・比較条件

### 2つの対話方略
同じ基盤LLM、同等の画像・履歴・課題情報、原則同じ会話能力・推論条件を使い、理解上の不確実性をどの程度その場で確認するかという方略の違いを比較する。

- **確認・修復を優先する条件**：不明確な内容や共有上の問題を検出したとき、必要な確認や再説明を比較的早く求める。
- **曖昧さを許容する条件**：必要なら直ちに修復しつつ、状況に応じて判断の保留、別の図形・論点への移行、後からの再処理、実用上十分な合意も選べるようにする。

どちらの条件でも自然な相槌や受容応答は使用できる。

本比較は「必ず質問する」対「質問を禁止する」という極端な比較ではない。厳密条件を同じ質問の反復で不自然に劣化させず、対話ログ上で確認・保留・再処理などの行動差が実際に生じたかを別途検証する。また、単なる確信度の低さを確認の必要性と同一視しない。

### 比較の形式
条件A・Bは同じ参加者が両方を体験する参加者内比較とし、AB／BAの順序を均衡化する。

### 対話モデルへの情報統制と画像の扱い
- **画像の扱い**：図形は実験者があらかじめ「鳥」「船」などの文章に変換せず、マルチモーダルLLMに画像として提示する。
- **情報統制**：対話モデルには、自分に提示された図形・課題指示、それまでに公開された発話・行動など、参加者がその時点で利用できる情報のみを与える。相手だけの画像、正解対応表、完成済みアノテーション、未来の発話、事後的な回答は渡さない（採点器が正解表を持つこととは厳密に分ける）。

### モデル構成の方針
形状・見立ての解釈と対象対応（どの図形を指しているか）の判断は、単一のマルチモーダルLLMに統合する方針を優先する。応答生成や課題制御（状態管理・提出の検査など）は別の構成要素として分離してよい。初期案にあった三層構造は固定の構成としない。

## 測定・評価

### 課題成功と主観的負担・円滑さ
まず共同命名の成功と誤対応を評価する。主観評価では、名前を決める会話中に使った精神的努力を尋ねる（必要以上に「会話中」と「名前の提出」を分けた設問にはしない）。そのうえで、人間側の精神的努力（負担）と会話の「円滑さ（停滞や手戻りが少なく進めやすい感覚）」を別々の概念として検討する。確認が多くても考える負担が軽い場合や、会話が速くても推測負担が重い場合を区別するためである。主観評価の質問紙と自由記述を組み合わせ、必要に応じて客観ログと照合する。

### 客観ログ
発話・ターン数、発話量、所要時間、確認・修復の回数、判断保留・再処理、誤りや未解決問題などを記録する。会話が短いことをそのまま認知負荷の低さとはみなさない。

### 同等性の扱い
本実験が期待するのは、課題達成を実質的に損なわずに負担または対話の停滞を抑えられるかの検証である。「成功率に統計的有意差がない」ことのみをもって同等と結論しない。

## 未決事項

以下の項目は、プロトコル設計および協議を進めている未決事項である。

- **尺度・設問**：主観評価尺度（NASA-TLX、Paasの精神的努力、PARADISE、BUS-15等）の採否や独自項目の文言・回答段階
- **意味のある効果の大きさ・許容できる成功率低下**：十分な成功維持とみなす基準および統計計画の策定
- **人数**：参加者数（サンプル数）の決定
- **確認の厳密さの操作方法**：プロンプトや判断モデルによる操作方法（閾値案は候補）
- **採点規則**：6図形中の部分成功、重複名、表記揺れ、未命名、時間切れの判定ルール
- **媒体（音声／テキスト）・時間制限**：対話媒体の選択および時間制限の有無・設定
- **使用モデル・API**：検証に用いるマルチモーダルモデルおよびAPIの選定
