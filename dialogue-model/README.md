# Dialogue Model

人間対話で観察された「やり過ごし」が、共通基盤形成にどのような役割を持つかを、対話モデルとして検証する領域です。

中心仮説は、共通基盤形成が「すべての理解上の問題を即時に完全修復する過程」ではなく、局所的な不確実性をその場で処理するか、保持するか、後続系列へ持ち越すかを調整しながら、共同活動に十分な共有を形成する過程である、というものです。

ここでの「やり過ごし」は、単なる失敗や見落としとしてではなく、判断保留、問題の持ち越し、不完全性を残した課題上十分な合意などを含む時間的な調整として扱います。

LLM は人間の内部認知過程を直接再現するものとして使いません。参加者と同様に、その時点までに利用できる発話と課題情報だけを与え、異なる調整方略からどのような対話系列が生じるかを比較する計算論的モデルとして使います。

アノテーション基準と Jev による一次判定支援は ../annotation/ に分離します。
