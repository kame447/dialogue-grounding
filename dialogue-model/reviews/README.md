# Research-design reviews

> 文書区分：議論・決定根拠の保存場所。実験計画の唯一の正本は[現行計画（SSOT）](../README.md)です。採用した変更は必ずSSOTにも反映し、このディレクトリの資料を独立した「最新版」として扱いません。

This directory stores review notes and experiment-design proposals from independent model critiques.
Files here are drafts until approved. Use dated filenames and preserve disagreements rather than rewriting them away.

For the 2026-10-12 Orrery review, the planned deliverables are an Opus 5.5 experimental-design draft, an independent Astra methodological critique, and an integrated response to critiques. Any adopted design must be reflected in dialogue-model/README.md (the SSOT); decisions/ records the reasoning and history rather than another current specification.

The private source annotations and manuscript binaries remain outside Git; see ../references/source-inventory.md.
