# Research-design reviews

> 現行の研究計画は[現行計画](../README.md)を参照してください。この文書は議論・決定の記録です。

This directory stores review notes and experiment-design proposals from independent model critiques.
Files here are drafts until approved. Use dated filenames and preserve disagreements rather than rewriting them away.

For the 2026-10-12 Orrery review, the planned deliverables are an Opus 5.5 experimental-design draft, an independent Astra methodological critique, and an integrated response to critiques. Any adopted design must be reflected in dialogue-model/README.md; decisions/ records the reasoning and history rather than another current specification.

The private source annotations and manuscript binaries remain outside Git; see ../references/source-inventory.md.
