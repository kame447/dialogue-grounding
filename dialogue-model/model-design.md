# LLM Dialogue Model Design

> 文書区分：論点別の参考メモ。現行の研究・実験計画の唯一の正本は[現行計画（SSOT）](README.md)です。内容が食い違う場合はSSOTを優先し、このメモの記述を採用済み実験仕様とはみなしません。

## 目的

LLM を用いて、人間対話で観察されたやり過ごしと同様の時間的調整が、限定された情報条件と単純な方略差から再現できるかを検証する。

これは人間の内部認知過程を直接証明する実験ではない。

同様の挙動を生成できる調整原理が、観察された対話現象を説明する計算論的な候補として十分かを検討する。

## 比較する基本方略

### repair-first

共有上の問題や不確実性が観察された場合、原則として即時に確認、聞き返し、再説明要求などの明示的修復を選ぶ。

### bypass-enabled

即時修復に加えて、次の行動を選択可能にする。

- 判断を確定せず、同一問題について相手の説明継続を許す
- 現在の問題を一旦保留し、別の対象や問題へ進む
- 完全な一致を確認せず、現在の課題に利用可能な暫定的共有を採用する
- 後続系列で必要になった場合に保留問題へ戻る

## 公平な比較条件

両方略は、同じ課題、同じモデル能力、同じ入力情報、同じ会話履歴条件で比較する。

差として与えるのは、局所的な共有上の問題に対してどの行動を選択可能とするかという調整方略である。

bypass-enabled にだけ正解情報や将来情報を与えない。

## 実装上の注意

研究者が付与した M/P ラベルを、原則としてモデルの行動選択入力には使わない。

モデル自身が、実際の参加者と同様に発話系列から不確実性や共有上の問題を扱う。

必要であれば、行動選択を「修復」「継続」「保留して移行」「暫定合意」などの閉集合にし、その後に自然言語発話を生成する二段階構成を検討する。

## 人間データとの対応

LLM の内部状態を人間の内部状態と対応付けるのではなく、観察可能な出力系列を比較する。

比較対象は、修復開始のタイミング、判断保留後の説明継続、問題の持ち越しと再処理、課題上十分な合意への収束などとする。
