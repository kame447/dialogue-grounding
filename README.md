# dialogue-grounding

共通基盤形成における「やり過ごし」の役割を研究するためのリポジトリです。

研究上の作業を、次の2領域に分離しています。

## annotation/

既存の人間対話を、発話系列上に観察可能な証拠に基づいて記述する領域です。

発話機能 a1–a30、ずれ状態 M0–M4、調整過程 P1–P6、エピソード結果 ER0/ER1、局所問題の後続処理を扱います。

Jev や生成モデルはアノテーション支援に使用しますが、参加者の「本当の内部状態」を推定することは目的にしません。

## dialogue-model/

[モデル研究の索引](dialogue-model/README.md)から、研究仮説、現行の設計資料、日付付き提案、確定した設計判断を辿れます。

[2026年10月12日付の初期実験案](dialogue-model/proposals/2026-10-12-initial-experiment-plan.md)には、今回検討した評価指標と三層構造を記録しています。

人間対話で観察された調整を、LLM を用いた対話モデルで検証する領域です。

中心仮説は、局所的な理解上の問題をすべて即時修復せず、判断保留や問題の持ち越しを行う「やり過ごし」が、共同活動に必要な共通基盤形成に機能的に寄与する場合がある、というものです。

LLM には、その時点までに参加者が利用できる情報だけを与えます。人間と似た挙動が再現できても、人間の内部認知過程そのものを証明したとは解釈しません。

## 役割分担

annotation/ は「人間対話で何が観察されたか」を記述します。

dialogue-model/ は「その現象を生み得る調整原理は何か」をモデルとして検証します。

この二つを分けることで、アノテーション自動化そのものを研究目的と混同せず、また研究者だけが利用できる事後情報を対話モデルへ混入させない構成にします。

実対話データ、音声、完成済みアノテーションファイル、個人識別情報はこのリポジトリへ保存しません。
