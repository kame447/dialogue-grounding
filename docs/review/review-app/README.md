# 主要領域確認用ローカルWebアプリ
実験本番の参加者画面とは独立した研究者用の確認アプリ。Node.js 24で追加依存なし。
```sh
node docs/review/review-app/server.ts
```
既定URLは http://127.0.0.1:5496/ 。保存先は ~/Library/Application Support/dialogue-grounding/figure-review-v1/review-state.json 。サーバーを再起動しても保存した分割・確認状態・入力途中の式・メモ・現在の図形を読み込む。直前の保存版は review-state.previous.json に保持する。図形データのハッシュが一致しない場合は既存の結果を自動的に置き換えない。複数タブの古いリビジョンによる上書きは拒否する。
式は + と / で入力する。切断済みピースは a/b の番号でも指定できる。入力ごとにMacへ保存し、通信できない場合はブラウザの一時退避と再試行を用いる。JSON書き出しには全30図形の状態、元の部品座標、選択された領域輪郭、式、切断線、データ識別情報が入る。以前の画面から取り出したテキストとJSONも読み込める。取り込み前の状態をバックアップし、取り込み元を保存する。
初期状態はF1の明示指定・6図形の修正案・残り23図形について前回確認済みとの申告を区別する。旧画面の具体的な編集結果は未取得なので、推測した初期案を確認済みの式と扱わない。旧画面に残る結果を取り込めれば、その式と確認状態を復元する。
ローカル専用で、実験runtimeや公開Workerへ組み込まない。保存ファイルはリポジトリへ入れない。
```sh
node --test docs/review/review-app/review-app.test.ts
```
