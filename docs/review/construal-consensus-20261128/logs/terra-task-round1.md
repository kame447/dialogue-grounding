## Role: tangram-observer
## Task summary: タングラム30図形（各1方向）の具体的な見立てを画像から独立に記述する（第1ラウンド）

## 背景
言葉で図形を指し示し合う対話実験で、AIが自分に提示された図形を観察する際の私的なメモに使う見立てを作っています。人が見てすぐ思いつき、相手に言葉で伝えやすい具体的な見立てを優先してください。あなたは独立した観察者の一人です。別の観察者（Claude Opus）も同じ画像を独立に観察しており、後で双方の案を照合します。

## 入力（作業ディレクトリ内のファイルだけを使う）
- `items.json`: 30項目の一覧。各項目に次があります。
  - `silhouette`: 白地に黒の無地シルエット（実験で提示される見た目）。
  - `regions`: 人手で確定した主要領域を色分けし、P1〜Pn の番号を付けた画像。色は区別のためだけで意味はありません。
  - 各領域の確定済み幾何情報: 形の名前、面積比（%）、図形全体に対する外接幅・高さの割合、重心位置の割合（左上原点、[横%, 縦%]）、三角形の頂点の向き、接する領域と方向。方向は画像上の上下左右です。
- 画像は必ず画像表示ツール（view_image など）で実際に開いて見てください。画像を開けない場合は推測で書かず、作業を止めて CherryCurie にその旨を報告してください。
- 分割・形・面積・接続は確定済みです。変更・再分割しないでください。複数の領域が一つの部位に当たる、一つの領域が二つの部位にまたがる、という対応付けは構いません。

## 独立性のための禁止事項

- 他の観察者と相談しないでください。

## 各項目の手順
1. まずシルエットだけを見て、全体が何に見えるかを考える。画面に表示された向きのまま見る。頭の中で回転させて「本来の向き」に直さず、この向きで自然に見えるものを書く。
2. 次に色分け画像を見て、候補ごとに P1〜Pn がそれぞれ何の部分に当たるかを対応付け、形・位置からの根拠を短く書く。
3. 候補は具体的な名詞にする（種・品物の水準で特定できる一般名）。「動物」「鳥」「魚」「虫」「道具」「乗り物」「建物」「塊」「図形」のような上位分類や、形容だけの候補は不可。人の形なら、何をしている人か（走る、座る、お辞儀する など）まで書く。
4. 無理に具体化しない。説得力のある見立てが無ければ「見立てなし」とし、理由を書く。候補は0〜3件。各候補に確信度（高・中・低）を付ける。
5. 各候補に、姿勢（例: 座っている、飛んでいる、立てて置かれている）と画面上の向き（例: 頭が左上、右向き、先端が下）を書く。
6. その見立てに合わない点（反証・弱点）も書く。

## 出力
作業ディレクトリに `round1-observations.json` を書く。形式:

```json
{
  "observer": "<あなたのORRERY名>",
  "model": "gpt-6.1-terra",
  "effort": "ultra",
  "viewedImages": true,
  "items": [
    {
      "item": "item-01",
      "silhouetteImpression": "シルエットだけを見た第一印象（1文）",
      "candidates": [
        {
          "rank": 1,
          "noun": "具体的な名詞",
          "posture": "姿勢",
          "direction": "画面上の向き",
          "confidence": "高|中|低",
          "parts": [{"id": "P1", "role": "部分の役割", "evidence": "形・位置からの根拠（短く）"}],
          "evidence": "全体としての根拠（1〜2文）",
          "weaknesses": "合わない点・反証（1文。無ければ空文字）"
        }
      ],
      "noConstrual": false,
      "noConstrualReason": "",
      "uncertainty": "迷った点・他の読み（1文）"
    }
  ]
}
```

- `parts` は各候補で P1〜Pn の全部を含める。その候補で役割の無い領域は role を「（対応なし）」とし、理由を evidence に書く。
- 見立てなしの場合は `candidates` を空配列、`noConstrual` を true にする。
- 30項目すべてを item 番号順に書く。10項目ごとに途中結果を同じファイルへ保存してよい。
- 最後に JSON として正しいか確認する（例: `python3 -m json.tool round1-observations.json > /dev/null`）。
