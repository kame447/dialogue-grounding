# 独立部分の見立て 468領域の合議（2026-11-28）

研究者の依頼（回転別・部分独立見立て）により、確定分割の全30図形・117領域を0/90/180/270度の4方向で見た468領域について、全体の見立てとは別に、各領域を単独で、または図形全体の中の位置・形との関係で見たときの具体的な部分の見立てを、Claude Opus 5.5 と GPT-6.1 Terra（effort ultra）が実画像から独立に観察し、同じ担当の組で直接合議して決めた案。**AIによる案であり、研究者の確認前で、正解名称ではない。** 実験runtime、参加者画面、本番、既存試行には反映していない。確定分割（117領域）と形・面積・位置・接続の幾何情報は変更していない。全体の見立ての合議（`../construal-consensus-20261128/`）とは別のフィールドとして扱う。

## 手順

1. **担当**: 回転角ごとに4組。a=270度（NobleMendel × PolarFeynman）、b=180度（AstuteOstwald × CherryHopper）、c=90度（DewyLinnaeus × SunnyBell）、d=0度（BreezyCopernicus × HardyGuericke）。Opus は `claude-opus-5-5`（effort max）、Terra は `gpt-6.1-terra`（effort ultra）。いずれも統括 BalmyDarwin が ORRERY の正規 delegate で起動した。各観察者は各図形を1方向だけ見る。項目番号は前回と同じ無作為な順で、図形 ID と回転角は伏せた（対応表は統括だけが保持）。
2. **第1段階（独立観察）**: 各領域について、具体的な部分の名詞の候補を0〜3件（`basis`: 単独・全体との関係・両方、確信度、短い幾何の根拠、弱点、任意の `owner`）。形・位置の言い換え（部分、突起、角、三角形など）や上位語は不可、無理に候補を出さない。図形全体の見立ては書かない。観察者への指示には**例示の名詞を入れていない**（前回の合議で例示語との重なりが制約として記録されたため）。
3. **第2段階（同じ組の合議）**: Opus は自分の第1段階を保存しハッシュを記録した後、Terra の第1段階完了の連絡を受けてから Terra の結果を読み、争点を `round2-request.md` にまとめて依頼した。Terra は `round2-crossreview-parts.json` で支持・反論・修正案を返した。採否は、両者が支持した候補だけを採用し（第2段階での明示の支持を含む）、確信度は両者の低い方、片方だけの候補は `discussion` に残した。
4. **統合と検証**（`integrate-part-consensus.ts`）: 4組の結果を図形・方向・領域 ID へ対応させ、468領域がそろうこと、各項目の領域 ID が catalog の順と一致すること、候補数0〜3、確信度・basis の値、候補なしと候補の有無の整合、未合意で候補を採用していないこと、曖昧な語（形の言い換え・上位語）が無いことを機械検証した。未合意の領域は候補を採用せず `agreementStatus: 未合意` で、候補なしの合意と区別する。

## 独立性

- 第1段階の各結果は、他者の結果を読む前に SHA-256 を記録した（`logs/sha256-round1.log`。Terra 4体は 07:28Z、Opus 4体は各自の報告時）。Terra の完了報告には見立ての内容を書かせず、パスと件数とハッシュだけにした。
- Opus 4体は、自分の第1段階を保存しハッシュを記録するまで Terra の結果を読まないと報告した（組 b は Terra の完了通知を受けた後も自分の観察を続けた）。

## 手順からの逸脱と制約

- 統括による画像を使った全件の品質確認（前回の全体の見立てで行った `qa-120.json` 相当）は未実施。Claude の利用枠（5時間枠）が観察中に約50%から約22%まで下がったため、統括の画像確認を後回しにした。研究者の確認画面での確認が終わるまで、すべて未確認の AI 案として扱う。
- CherryHopper（Terra b）は、出力 JSON の `model` を「GPT-6（詳細ID不明）」、effort を「不明」と記載した。起動時の指定と画面表示は `gpt-6.1-terra`・`ultra`。
- NobleMendel（Opus a）は約240KBの合議結果を、予約を取ったうえでシェルで書き込み、直後に予約を解放したと報告した。
- Codex の週間利用上限の残りは、観察の開始時に4%、終了時に3%と表示された。全組が両段階を完了した。
- 見立ては形からの仮説で、同じ名詞（頭・尾・耳・脚・くちばし・翼など）が多くの方向に付く。部分の見立ての一致だけで対象や合意を確定しない前提で使う。
