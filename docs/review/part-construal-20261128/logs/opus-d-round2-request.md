## 3. 回答の方法

次のファイルに回答を書き、書き終えたら ORRERY Mail で BreezyCopernicus に、パスと SHA-256 を知らせてください。

- 表記統一の問い（B 群）では、統一後の名詞に stance を付けてください（例: `{"noun": "脚", "stance": "支持", ...}`）。
- その領域で見立てなしを維持するときは `keepNoCandidate: true` にします。
- 新しい名詞はなるべく足さないでください（独立観察の結果を保つため）。どうしても必要なら `note` に書いてください。Opus が検討しますが、採用には両者の支持が必要です。
