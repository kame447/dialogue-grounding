## 5. 返信の形式

`/Users/Shogo/Research/dialogue-grounding/private-runs/2026-11-28-rotation-memory-implementation/part-construal-v1/terra-b/round2-crossreview-parts.json` に保存し、パスと SHA-256 を ORRERY Mail の send_message で AstuteOstwald に知らせてほしい。形式は次のとおり。これと同じ内容が読み取れるなら、形式は多少違ってもかまわない。

```json
{
  "reviewer": "CherryHopper",
  "readOpusRound1": true,
  "viewedImagesAgain": true,
  "unification": {"C1": "同意 または 不同意（理由）", "C2": "…", "C3": "…"},
  "items": [
    {
      "item": "item-01",
      "regions": [
        {
          "id": "P1",
          "opusVerdicts": [
            {"noun": "腕", "verdict": "支持|不支持", "confidence": "高|中|低", "reason": "1文"}
          ],
          "terraFinal": [
            {"noun": "足", "status": "維持|撤回", "confidence": "高|中|低", "reason": "1文"}
          ],
          "comment": ""
        }
      ]
    }
  ]
}
```

- 30項目すべてと、items.json のすべての P ID を、番号順に含めてほしい。
- `opusVerdicts` には、その領域の Opus 第1段階の候補をすべて入れる。一致済みの候補も「支持」と明記する。Opus の候補がなければ空の配列にする。
- `terraFinal` には、その領域の Terra 第1段階の候補をすべて入れ、維持か撤回かを書く。Terra の候補がなければ空の配列にする。
- 第1・2節の一致や見立てなしに異議があれば、該当領域の `comment` に書いてほしい。
- 第2段階で新しい候補を出すことは原則として避けてほしい。出す場合は `comment` に書く。合意案では片方だけの候補として扱い、Opus が画像を見直して支持した場合だけ採用する。
